# Code of Conduct

This project aims to be a respectful and productive space for collaboration.

## Expected Behavior

- Be considerate and constructive.
- Assume good intent while making room for correction.
- Keep technical feedback specific and actionable.
- Respect differences in experience level and background.

## Unacceptable Behavior

- Harassment, discrimination, or personal attacks.
- Dismissive or hostile communication.
- Sharing private information without permission.

## Reporting

If you notice behavior that makes collaboration difficult or unsafe, please raise it with the repository maintainer.
